Sintaxis HTML

Etiqueta:
    De cierre
        <nombre-etiqueta> </nombre-etiqueta>
    
    De autocierre
        <nombre-etiqueta/>
        
        <nombre-etiqueta>


Elemento:
    Quien determina la funcionalida/significado de la etiqueta es el elemento 
    El elemento determina el tipo de etiqueta, solo puede ser un tipo de etiqueta
    Por ejemplo.
        h1 (de cierre): significa el titulo de nuestra pagina
        button(de cierre): Significa un boton de la pagina
        img(de autocierre): Significa una imagen
        p(de cierre): Significa un Parrafo
        a(de cierre): Significa un hipervinculo (link)
        ul(de cierre): Significa lista desordenada
        ol (de cierre): Significa lista ordenada
        li(de cierre): Significa item de lista.
        b(de cierre): Letra Negrita

Atributos:
    Cada elemento tiene disponibles una serie de Atributos
    El Atributo es una configuracion del elemento
        Ejemplo <caja tamaño='chica' color='rojo' con-puntas='redondeadas'></caja>
        Ejemplo real: <a href='link'>Ir a Pagina</a>


Anidamiento:
    La capacidad de que una etiqueta contenga otra etiqueta
    <padre><hijo></hijo></padre>

Buena Practica: Indetacion (Poder ordenar visualmente nuestros elementos para entender la jerarquia)
    En lugar de asi
  <padre><hijo><nieto></nieto></hijo><hijo></hijo></padre>
    Hacerlo
    <padre>
        <hijo>
            <nieto></nieto>
        </hijo>
        <hijo></hijo>
    </padre>
